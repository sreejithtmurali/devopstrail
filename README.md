1. runApp() is the entry point of every flutter app,it takes the root widget and display it on screen
2. MaterialApp is a widget that provides Material Design featuers to your app. it acts as
   The main container for your application
   it provides:-
   1. app navigation
   2. themes
   3. title
   4. debug banner
   5. localization
   6. home

   it offers ready- made sections such as
   1. appBar
   2. body
   3. bottomNavigationBar
   4. floatingActionButton
   5. drawer 
   6. backgroundColor
